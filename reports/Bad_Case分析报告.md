# 成员D：本地检索Bad Case分析与优化报告

日期：2026-10-08

## 1. 评测范围

- 评测集：52题，覆盖事实性、对比性、归纳性和推理性问题。
- 语料库：10篇论文，其中P01–P02为中文，P03–P10为英文。
- 索引：1,013个文本分块，向量模型为`BAAI/bge-large-zh-v1.5`。
- 检索配置：TopK=5，向量检索与BM25通过RRF融合；本轮关闭Reranker，保证优化前后配置一致。
- 数据边界：全过程离线运行，没有调用外部大模型API。

## 3. 根因分析

### 3.1 跨语言词汇不对齐

中文问题中的“历史帧阈值”“弱监督”“声呐”“折射”等概念，在英文论文中使用不同表达。中文查询对英文分块的BM25贡献接近零，向量召回也会随专业词密度下降。

### 3.2 RRF按分块融合造成来源垄断

多个Bad Case中，相关英文论文在向量通道实际位于前1至3名，但P01–P02的分块同时获得向量和中文BM25分数。RRF叠加后，同一中文论文的多个分块占满Top5，使已经被向量通道召回的英文论文再次被挤出。

### 3.3 TopK缺少来源多样性约束

原实现只按`chunk_id`排名，没有限制单篇论文进入Top5的分块数量。对跨论文问题，这会降低文档级Recall，也减少RAG可使用的证据来源。

## 4. 已实施优化

1. 新增本地科研术语双语扩展。只有查询命中领域术语时才追加英文别名；不调用翻译API，不绑定问题ID、论文ID或标准答案。
2. 将扩展后的同一查询同时用于向量检索和BM25。
3. 最终TopK中单篇来源最多保留2个分块，防止单篇论文重复占位。
4. 优先保留向量通道前2个不同论文来源，再由RRF补齐其余结果，避免英文论文被中文BM25叠加分数完全挤出。
5. 新增3项跨语言检索单元测试，并与既有引用去重、索引删除测试共同执行，6项测试全部通过。

可配置项：

```text
ENABLE_CROSS_LANGUAGE_EXPANSION=true
HYBRID_MAX_CHUNKS_PER_SOURCE=2
HYBRID_VECTOR_SOURCE_RESERVE=2
```

## 8. 仍需关注的风险

1. 本轮术语表依据当前水产计算机视觉语料构建，必须用新增的未见问题做留出集复测，避免只适配当前52题。
2. 对比性问题的Recall@5为0.875，说明部分双论文问题仍只召回了其中一篇；后续可研究按问题意图动态调整来源上限。
3. 本报告只完成“检索失败”类Bad Case闭环。生成错误、引用错误和Agent决策错误需在获得外部API数据发送授权并完成双通道批跑后补充。
4. Reranker在本轮受控对比中关闭。正式报告应单独比较启用与关闭Reranker的效果，不能把本轮结果直接当成所有配置下的结论。

## 9. 完成判定

本地检索Bad Case已完成一轮“发现问题—根因分析—代码优化—单元测试—真实接口口径52题复测—前后指标对比”的闭环。课程要求中的“至少一轮优化及前后对比”已在检索层满足；完整系统级Bad Case仍需等待RAG和Agent双通道评测。
