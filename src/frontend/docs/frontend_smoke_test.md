## B. 待真机执行的端到端联调清单（任务 #9）

> 前提：在你自己的终端进入 `smart-research-assistant` 目录，`.env` 已配 API Key，
> 模型可正常加载（首次会自动下载 embedding/reranker）。

1. **后端起服**：`python main.py` → 控制台出现框线提示；浏览器开 `http://localhost:8000/docs` 可见 Swagger。
2. **前端起服**：`streamlit run src/frontend/app.py` → 打开 `http://localhost:8501`。
   - 预期：顶栏 `🔌 RAG 直连` 徽标、右栏系统监控显示向量数（已有 PPO 论文 33 chunks 索引）。
3. **文档上传**：左栏选 1~2 篇 PDF → "🚀 上传并构建索引" → 观察 st.status 逐项进度与
   ✅ 页数/块数结果；列表出现 🟢indexed。
4. **流式问答**：中央输入"这篇论文的主要方法是什么？" → 预期顺序：
   ⏳状态行 → 📎引用徽章先出现 → 正文打字机 → 右栏本轮指标（耗时/Token/引用数）出数。
5. **缓存命中**：同一问题立即再问一遍 → thinking 应出现"命中缓存，直接返回"，几乎秒回。
6. **删除文档**：左栏 🗑 → 列表移除、后端日志 `文档已删除`。
   （注意：索引向量不会同步清理，属后端接口现状，已在 module4_design.md §8 记录。）
7. **会话管理**：➕新建 → 旧对话消失；左栏下拉切回旧会话 → 历史完整重放；
   🗑删除当前 → 会话文件从 `src/frontend/sessions/` 移除。
8. **边缘场景**（作业 5.4.4 要求）：
   - 空知识库提问 → 显示后端 FALLBACK 降级文案（非报错）；
   - top_k 拉到 20 提问 → 回答变慢但正常；
   - 后端运行中 Ctrl+C 杀掉 → 前端红条即时提示"后端服务不可用"，界面不崩；
   - 超长对话（>20 轮）→ 前端历史可滚动回放（记忆压缩属模块三）。
9. **模块三接入演练**（他交付后）：`.env` 加 `USE_AGENT=true` 重启前端 →
   右栏出现 Thought→Action→Observation 轨迹树；若他端点还没好 → 前端自动降级并显示
   "⚠️ Agent 通道尚未就绪…已自动降级"，功能照常。
