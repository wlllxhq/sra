## 3. 关键用例实测记录

### 3.1 Agent 通道 · 历史第一轮（2026-09-30 21:13）
指代模糊提问"这篇论文使用的模型是什么？"→ 5 轮 ReAct（search→paper_meta→分篇 search×3）→触顶强制收敛→跨 3 篇分条作答带页码引句。**5 轮/19 引用/21522 Token/34.71s**，会话 JSON 完整持久化。后端日志：
```
21:13:17 Agent查询 → 第1~5轮 knowledge_search/paper_meta×1/search×3
21:13:49 WARNING 达到最大轮次5，强制生成回答
21:13:51 ReAct完成: 5轮, 19条引用, 21522 tokens, 34.71s
```

### 3.2 Agent 通道 · 历史第二轮（2026-10-01）
"这篇论文用了什么数据集？"→ 5 轮/20 引用/40.8s/25101 Token；识别指代不明后按 4 篇（含已删残留）分条作答；右栏引用卡片、T→A→O 轨迹树、Agent 指标（成功率 100%）全部正常渲染。回答引用了不在文档列表中的论文 → **印证 D1**。

### 3.3 Agent 通道 · 本轮自动化实测（2026-10-10 Phase1）
- TC07 Q1"第一篇论文（覃学标）用了什么深度学习模型？"：事件序列 `status→thought→action(knowledge_search)→observation→thought→action→observation→thought→reference×16→delta×39→final`，8.58s / 7353 Token / done.reference_count=16，**恰好单一收尾事件**；
- TC08 Q2"它的实验数据集规模有多大？"（同 session）：**未反问指代对象**，1 轮检索即定向覃学标论文作答（7 引用/4746 Token/5.07s）；
- TC08b 记忆回验 Q3"刚才第二个问题你回答的是哪篇论文？"→ 答"第一篇论文覃学标的《基于目标检测及边缘支持的鱼类图像分割方法》……分割原理类似 Mask R-CNN……"，**跨轮实体保留确证**；
- TC06 RAG 直连同题：668 个 delta、5 引用、31.28s、答案 1228 字，流式与引用先行均正常；**done.token_count=0** → 新缺陷 D5。

### 3.5 空知识库提问（2026-10-10 15:12，TC11 补跑）
前置：`index` 重命名为 `index_bak` 后重启后端，health 确认 vector_count=0（documents 列表仍显示 2 个文件但 chunks=0，此不一致本身再次印证 D1 家族问题）。
- **RAG 直连**：事件流 `status×2 → delta×1 → final×1`，零引用、零错误；回答为标准降级话术："当前知识库中未找到与您问题相关的文档内容……建议您确认相关论文已上传并成功索引……"——命中模块二 FALLBACK_PROMPT 设计路径 ✅

- 收尾复查：两轮提问后 vector_count 仍为 0、cache_size 仍为 0，空库提问不产生任何脏数据 ✅
